


The app is called HandicraftsApp,
In this application, users who are interested in handicrafts can review products, identify their favorite products and purchase them through the application. Craftspeople can showcase their own products through the app, allowing them to reach a wide audience.
The application is developed using SwiftUI. It uses Firebase infrastructure.  User login and data storage operations were performed using Firebase Authentication and Firestore.

USAGE AREAS

Users can view and review handicraft products.

Users can purchase products of handicraft artists as a member.

Craftsmen can exhibit their own products through the application.

Users can set their favorite products and review these products later.

They can purchase products through the shopping cart.

Users can discover handicraft products according to categories within the application.



HandiCraftsApp---MVVM (No Storyboard)
I honed my skills by creating a Programmatic user interface, which is different from the common e-commerce applications built in bootcamps. I built a 10-scene project using the MVVM design pattern. I followed the Firebase documentation for user creation and login. This allowed me to write user data to FirestoreDatabase and use the data by uploading user product images to FirebaseStorage. I presented these features to the user by leveraging the functions presented in Firebase's documentation.

Translated with DeepL.com (free version)
Key Features
--Support: iOS 13+

-Architecture: MVVM

-UI: Custom Components - Full Programmatic(SnapKit)

-Memory: No Retain Cycles

-Backend: Firebase(FirebaseAuth, FirestoreDatabase, FirebaseStorage)


-3rd party libraries: Snapkit
